Compound Engineering × flywheel / toron / beads

Every's CE plugin (33 skills, MIT) studied against our compose-token / stage / playbook stack — what maps, what's missing, what to port, what to refuse. Sources: EveryInc/compound-engineering-plugin (README, CONCEPTS.md, skill guides) × src/stages.rs, src/builtin_workflows.rs, src/crew.rs, ADR-0006/0008/0027/0028.

Verdict: we already have CE's discipline half — contracts, gates, bounded repair, evidence receipts, human signoff (in places stronger than CE, via durable mail + beads two-step close). We are missing CE's compounding half: the learning return arrow (nothing reads past lessons at dispatch; lessons are hand-curated into AGENTS.md/skills by the captain) and a true adversarial review (wave-VERIFY audits receipts and close-reason tails, not the artifact itself — the exact hole the torondev "garbage stub catalog claimed as real" lane fell through).
P0 — zero-code, project tier, works today P1 — one small Rust PR P2 — ADR-0029 tier 4 concepts deliberately rejected

1Loop vs loop — where CE's six steps already live in our tokens

ce-brainstorm → beads-lifecycle: grill HAVE

Grill sharpens the objective against ADR/goal JSON before bead creation — same shape as CE's requirements-only artifact.

ce-plan → create → review1 → review2 → integrate HAVE

Two bead-graph review passes (@reviewer plan-review + @oracle judge-arms) ≈ CE's doc-review personas. Missing only CE's readiness levels (requirements-only vs implementation-ready).

ce-work → wave-swarm: DISPATCH→EXECUTE HAVE

systematic-execute brief (GOAL/SCOPE/CONTEXT/ACCEPTANCE/VERIFY/TIMEBOX/FORBIDDEN/REPORT/PRINCIPLES/STANDING) is CE's "outcome spine" — result, done-bar, safe-failure direction — already enforced.

ce-simplify-code → GAP (minor)

No behavior-preserving refinement pass between EXECUTE and review. Cheap to fold into systematic-execute ("simplify as you go") — CE itself demoted it to mid-work.

ce-code-review → GAP (major)

No persona-panel diff review anywhere in wave-swarm. VERIFY = receipt-at-HEAD + tail + principles citations = audits the claim, never the code.

ce-compound → GAP (the point)

Nothing writes learnings at wave end. PHASES = [resolve, plan, implement, review, verify] — no compound phase exists in the vocabulary. weekly-review produces ONE follow-up bead, not a corpus.

wave-swarm today vs the compound wave. New steps are ordinary stages — the compose grammar already chains them (--parts wave-swarm,reviewer:wave-review is legal today).

3Phased plan

P0

Zero-code, project tier — works with today's binary

  • Create docs/learnings/ + convention (schema below) + one discoverability line in AGENTS.md.
  • Project-tier .flywheel/stages.toml: add wave-review (phase review — legal vocabulary today) with persona + detection-condition + evidence-quote + independence doctrine.
  • Override wave-verify prompt: + residual gate (unfixed finding ⇒ bead id or it fails), + artifact-not-essay rule.
  • standing-orders additions: terminal-state vocabulary in reports, idempotent re-entry rule, settled: labels, scout evidence-dossier habit.
  • Chain it today: flywheel workflow compose "<obj>" --parts wave-swarm,reviewer:wave-review --run — the grammar already supports token + part.
P1

One small Rust PR — the compound spine lands properly

  • PHASES += "compound" (src/stages.rs, one line + lint vocabulary).
  • Compiled-in seed stages wave-review + wave-compound; wave-swarm YAML 6 → 8 steps (REVIEW after OBSERVE, COMPOUND after VERIFY with on_error: continue — a failed capture never blocks signoff; SIGNOFF message reports "learnings: N captured / M deferred").
  • Report contract (D4) + evaluate JSON: terminal + clean_skip.
  • Skill Sync Contract, all four surfaces: Commands enum docs, robot_capabilities, AGENTS.md, skill §5 + CHANGELOG. Tests: 8-step expansion lints clean, compound phase valid, clean_skip parses.
P2

ADR-0029 "compound spine" — the structural pieces

  • Stage.refs (phase-loaded kernel; body = spine + stop classes, mechanics in reference files loaded at the acting step).
  • Model identity receipt wiring (presence/report diff → observe digest).
  • compound-sweep cron builtin: Keep/Update/Consolidate/Replace/Delete over the corpus + CE's guidance-layer rule (a learning contradicting standing-orders/AGENTS.md outranks ordinary staleness; resolve by which side the code follows). Extends weekly-review's family.
  • Principles candidates (registry ADR needed): score-artifacts-not-essays, state-the-condition-not-the-cases.
  • GATE readiness check: a bead without VERIFY+scope is held as not-execution-ready (CE's requirements-only vs implementation-ready).
